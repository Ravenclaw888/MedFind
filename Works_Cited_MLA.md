# Works Cited — Clinical Specialty Navigator

This is the complete MLA 9 works-cited list for the 33 external medical sources embedded in the current app. Each entry includes the app's source ID so it can be matched to the in-app source list and to its use in a routing pathway. Pages without a stated publication date are cited without one, following MLA guidance. The original sources were accessed 27 Sept. 2026; version 0.3 and 0.4 additions were accessed 28 Sept. 2026. Version 0.6 adds broad NHS Inform A–Z candidate-service mappings using the existing NHS Inform index source and ABMS specialty taxonomy; it introduces no additional external sources.

> This directory list describes sources, not clinical decision rules. The app is an educational referral-navigation aid and is not a diagnostic or emergency-triage service.
